# Thapsus website

Marketing website for Thapsus: custom software for UK businesses, built in Stockport.

Built with Next.js (App Router), Tailwind CSS, GSAP + ScrollTrigger and Lenis.

## Run locally

```bash
npm install
npm run dev        # http://localhost:3000
```

Production build:

```bash
npm run build
npm start
```

## Edit content

Contact details, legal details, the accent colour, prices and calculator settings all live in
[`src/config/site.ts`](src/config/site.ts).
